# 🧾 FreshStock

Sistema de inventario para productos perecibles desarrollado en PHP + MySQL.

## 🚀 Funcionalidades
- Registro de productos (CRUD)
- Control de stock mínimo
- Detección de productos vencidos y por vencer
- Dashboard con KPI:
  - Total productos
  - Bajo stock
  - Vencidos
  - Ganancia estimada
- Exportación a CSV

## 🖥️ Tecnologías
- PHP
- MySQL
- HTML + CSS
- XAMPP

## ⚙️ Instalación
1. Clonar repositorio
2. Copiar en:
   C:\xampp\htdocs\
3. Crear base de datos en phpMyAdmin
4. Importar archivo `.sql`
5. Ejecutar:
   http://localhost/freshstock

## 📊 Base de Datos

Tabla: productos

Campos:
- id
- nombre
- stock
- stock_min
- precio_compra
- precio_venta
- fecha_vencimiento
